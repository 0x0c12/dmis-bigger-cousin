# dmis-bigger-cousin
I was pretty pissed off spamming dmi af dmi af in r2 so I made a little helper script that does it for you :3

# quick warning
the script itself relies on being in debug mode, so make sure you launch your binary with the `-d` flag.
An example command would be like this:

```sh
  r2 -i debug.r2 -A -d /path/to/ur/binary
```
